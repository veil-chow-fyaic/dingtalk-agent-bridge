管理钉钉日历：日程、参会人、会议室、闲忙、附件、日历本、访问权限。调用前必须先使用 --help 查看参数结构。

命令结构:
  dws calendar event       [list|get|create|update|delete|suggest|respond|instances|share-info]  日程管理
  dws calendar attendee    [list|add|delete]                 参会人管理
  dws calendar room        [search|add|delete|list-groups]   会议室管理
  dws calendar busy        search                           闲忙查询 (可查人、查会议室)
  dws calendar attachment  add                              日程附件管理
  dws calendar book        [list|get|search|update]          日历本管理
  dws calendar acl         [list|add|delete]                 日历访问权限管理

Usage:
  dws calendar [flags]
  dws calendar [command]

Available Commands:
  +agenda        查询日程列表（不传时间默认查询今天）
  +attendee-list 查看日程参会人
  +book          创建日程，并可按姓名邀请参会人（自动解析 userId，失败自动回滚删除日程）
  +book-list     查询用户的日历本列表
  +book-search   按名称模糊搜索日历本
  +cancel-event  取消（删除）一个已有日程（删除前先确认它真实存在）
  +conflicts     检测我某天日程的时间冲突（重叠/双重预订，默认今天）
  +create        创建日程并读回验证
  +free          按姓名查询某人在指定时间段内的忙闲状态（自动解析 userId）
  +free-slots    找我某天工作时段内的空闲时间段（默认今天 09:00-18:00）
  +freebusy      查询用户 / 会议室闲忙状态（--users 与 --rooms 至少其一）
  +get           严格获取日程详情
  +invite        按姓名把参会人加入已有日程（自动解析 userId 后批量添加）
  +my-free       查我自己在某时间段的忙闲（默认今天，无需输入姓名）
  +next-event    查看接下来最近的一个日程（默认扫描未来 7 天）
  +reschedule    改一个已有日程的时间（只动开始/结束时间，其他字段不变）
  +room-find     按时间段搜索可用会议室（不传时间默认当前起 1 小时）
  +room-groups   会议室分组列表
  +room-search   按名称模糊搜索会议室（不检查可用性）
  +rsvp          响应日程邀请并读取终态
  +search-event  在一个日程页内严格搜索事件
  +suggest-time  按姓名解析多位参与者，推荐大家都有空的可开会时间段（自动解析 userId）
  +suggestion    按 userId 严格推荐共同空闲时间
  +today         列出我今天的日程（自动计算今天的起止时间，无需手动填时间范围）
  +tomorrow      列出我明天的日程（自动计算明天的起止时间，无需手动填时间范围）
  +update        分阶段更新日程并读回验证
  +week          列出我本周的日程（自动按周一为周首计算本周起止时间，无需手动填时间范围）
  acl            管理我的日历访问权限（共享给他人）
  attachment     日程附件管理
  attendee       日程参会人管理
  book           日历本管理（我能看哪些日历）
  busy           闲忙查询
  event          日程管理
  room           会议室管理

Flags:
  -h, --help   help for calendar

Global Flags:
      --client-id string       覆盖 OAuth 客户端 ID (钉钉 AppKey)
      --client-secret string   覆盖 OAuth 客户端密钥 (钉钉 AppSecret)
      --debug                  显示调试日志
      --dry-run                预览操作内容，不实际执行
      --fields string          筛选输出字段 (逗号分隔, 如: name,id,status)
  -f, --format string          输出格式: json|table|raw|pretty|ndjson|csv (default "json")
      --jq string              jq 表达式过滤输出 (如: '.items[] | .name')
      --mock                   使用 Mock 数据 (开发调试用)
      --profile string         一次性指定组织或账号；支持 corpId/corpName 与 userId/userName 组合，推荐使用 profile list 返回的 corpId:userId；多个按 CSV 逗号分隔
      --timeout int            HTTP 请求与文件直传超时时间 (秒)；文件直传最低保留 5 分钟 (default 30)
  -v, --verbose                显示详细日志
  -y, --yes                    跳过确认提示 (AI Agent 模式)

Use "dws calendar [command] --help" for more information about a command.

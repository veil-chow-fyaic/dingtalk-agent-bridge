当你要以当前用户身份对一条已有消息发送纯文本引用回复时使用；传原消息 ID，CLI 会只读定位会话和发送者；可显式传会话或 --ref-sender，所有模式均核对源消息身份。可用 --as bot 选择 Bot 群引用，--open-dingtalk-id 选择个人单聊，--reply-in-thread 追加到已核实的 Thread；所有模式先检查源消息 ID/会话归属；个人普通引用的 markdown/content 仍按纯文本解释，群聊可显式 @成员或 @所有人。成功结果在保留下层响应的同时增量返回 messageId（下层提供时）、conversationId、threadId（适用时）、deliveryStatus、idempotencyKey 和 referencedMessage 来源上下文。

参数约束：
  - Bot 仅普通群引用且必须有 robot-code；Thread 仅 user，与单聊和 ref-sender 互斥；thread-id 必须与源消息一致
  - 省略会话时从源消息只读定位；显式会话/发送者必须匹配，所有模式均校验源消息；@仅群聊，成员使用openDingTalkId
  - --ref-msg-id、--message-id 必须且只能指定一个
  - --uuid、--idempotency-key 互斥，最多指定一个

Usage:
  dws chat +messages-reply [flags]

Examples:
  dws chat +messages-reply --group <openConversationId> --message-id <openMessageId> --content "收到" --idempotency-key <key>

Flags:
      --ai-tag                         消息是否带 AI 发送角标（默认 true） (default true)

      --at-all                         群回复中 @所有人；省略会话时从源消息只读定位；显式会话/发送者必须匹配，所有模式均校验源消息；@仅群聊，成员使用openDingTalkId
      --at-open-dingtalk-ids strings   群回复中 @ 的 openDingTalkId 列表；自动补齐缺少的提及占位符；省略会话时从源消息只读定位；显式会话/发送者必须匹配，所有模式均校验源消息；@仅群聊，成员使用openDingTalkId (default [])
      --body-stdin                     从 stdin 读取最多 256 KiB 正文；选中的正文参数必须为 -，不改变默认字面量行为
      --content string                 回复正文；普通引用中 content/markdown 均按纯文本解释，Bot群引用及已有Thread追加为Markdown；@仅群聊，可用 <@openDingTalkId> 定位提及（必填）

      --group string                   可选会话 openConversationId；省略会话时从源消息只读定位；显式会话/发送者必须匹配，所有模式均校验源消息；@仅群聊，成员使用openDingTalkId

      --message-id string              --ref-msg-id 的 lark-cli 对齐别名
      --open-dingtalk-id string        个人单聊接收者；可省略 --group，自动读取源消息会话核实；Bot 仅普通群引用且必须有 robot-code；Thread 仅 user，与单聊和 ref-sender 互斥；thread-id 必须与源消息一致；省略会话时从源消息只读定位；显式会话/发送者必须匹配，所有模式均校验源消息；@仅群聊，成员使用openDingTalkId

      --uuid string                    幂等键（可选）；Bot 仅普通群引用且必须有 robot-code；Thread 仅 user，与单聊和 ref-sender 互斥；thread-id 必须与源消息一致

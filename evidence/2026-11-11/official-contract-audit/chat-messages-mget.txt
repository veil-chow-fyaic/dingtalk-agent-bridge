当你已有一批消息 openMsgId、需要批量取回完整详情、reaction 和可执行资源引用时使用；一次最多 50 条；ID 参数错误会有界拆分隔离，其他错误停止拆分；默认主动补查 Reaction 和每个 Thread 最多 10 条回复，使用 complete、messagesComplete、enrichment 披露完整性。--download-resources 可把所有可识别 mediaId/fileId 安全下载到工作目录内，并逐资源返回成功/失败 ledger；本地下载路径受限于工作目录、默认不覆盖同名文件，按既有安全下载约定无需交互确认。

参数约束：
  - --msg-ids 去重后必须包含 1-50 条消息 ID
  - --output-dir 必须是工作目录内的相对路径，不允许绝对路径或 .. 逃逸

Usage:
  dws chat +messages-mget [flags]

Examples:
  dws chat +messages-mget --msg-ids msgId1,msgId2

Flags:
      --download-resources   自动下载消息中的全部可识别 mediaId/fileId 资源
  -h, --help                 help for +messages-mget
      --msg-ids strings      消息 openMsgId 列表，兼容 --message-ids / --message-id；--msg-ids 去重后必须包含 1-50 条消息 ID（必填） (default [])
      --no-reactions         跳过主动 Reaction 补查并不输出 Reaction（默认补查，每批最多 20 条）
      --no-threads           跳过 Thread 回复补查（默认每个 Thread 最多 10 条、总计最多 500 条；需要完整回复请用 +thread-replies）
      --output-dir string    资源输出目录；必须是工作目录内的相对路径，禁止绝对路径和 .. 逃逸 (default "./downloads")
      --overwrite            允许覆盖工作目录内已存在的本地输出文件（默认拒绝）

Global Flags:
      --client-id string       覆盖 OAuth 客户端 ID (钉钉 AppKey)
      --client-secret string   覆盖 OAuth 客户端密钥 (钉钉 AppSecret)
      --debug                  显示调试日志
      --dry-run                预览操作内容，不实际执行
      --fields string          筛选输出字段 (逗号分隔, 如: name,id,status)
  -f, --format string          输出格式: json|table|raw|pretty|ndjson|csv (default "json")
      --jq string              jq 表达式过滤输出 (如: '.items[] | .name')
      --mock                   使用 Mock 数据 (开发调试用)
      --profile string         一次性指定组织或账号；支持 corpId/corpName 与 userId/userName 组合，推荐使用 profile list 返回的 corpId:userId；多个按 CSV 逗号分隔
      --timeout int            HTTP 请求与文件直传超时时间 (秒)；文件直传最低保留 5 分钟 (default 30)
  -v, --verbose                显示详细日志
  -y, --yes                    跳过确认提示 (AI Agent 模式)

Usage:
  dws chat +chat-messages [flags]

Aliases:
  +chat-messages, +chat-messages-list

Examples:
  dws chat +chat-messages --group <openconversation_id> --time "2025-03-01 00:00:00"
  dws chat +chat-messages --group <openconversation_id> --start "2025-03-01T00:00:00+08:00" --end "2025-03-02T00:00:00+08:00" --order asc --page-all
  dws chat +chat-messages --user <userId> --time "2025-03-01 00:00:00" --page-all --page-limit 50
  dws chat +chat-messages --group <openconversation_id> --direction older --page-all --output ./exports/messages.json
  dws chat +chat-messages --group <openconversation_id> --direction older --jq '.messages[] | {messageId, text}'

Flags:

      --direction string          时间方向 newer/older；省略时为 older，从时间边界向前读取（可选值: newer, older）
      --download-resources        自动下载消息中的全部可识别 mediaId/fileId 资源
      --end string                范围结束时间（可选、不包含）；仅传开始时间时默认为当前时间
      --end-time string           --end 的 lark-cli 对齐别名（可选、不包含）
      --group string              群名称或 openConversationId，与单聊目标互斥

      --max-results int           --max-items 的公开兼容别名；--max-results 仅与 --page-all 一起使用且不能为负数
      --no-reactions              不输出消息 reaction（默认输出）
      --open-dingtalk-id string   单聊对方的 openDingTalkId，与 --group/--user 互斥

  -o, --output string             把完整结构化 ledger 原子写入工作目录内的相对 JSON 文件
      --output-dir string         资源输出目录；必须是工作目录内的相对路径，禁止绝对路径和 .. 逃逸 (default "./downloads")

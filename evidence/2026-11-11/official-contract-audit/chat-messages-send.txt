按身份发送消息；user 的 Markdown 可内联本地图片，先上传并以单条富文本发送。bot/webhook 不支持本地 Markdown 图片。

参数约束：
  - --text、--markdown、--media-id、--file、--file-path、--image-url、--contact-id、--share-chat-id、--a2ui-messages 至少指定一个
  - --text、--markdown、--media-id、--file、--file-path、--image-url、--contact-id、--share-chat-id、--a2ui-messages 互斥，最多指定一个
  - --identity、--as 互斥，最多指定一个
  - --group、--chat-id 互斥，最多指定一个
  - --user、--open-dingtalk-id 互斥，最多指定一个
  - --uuid、--idempotency-key 互斥，最多指定一个
  - 目标、凭据和幂等参数受发送身份能力矩阵约束：user 必须指定一个群聊或单聊目标；bot 必须指定 robot-code 和一类目标，多群最多 100 个并逐项返回 ledger；webhook 必须指定 webhook-token；幂等键仅 user 支持

Usage:
  dws chat +messages-send [flags]

Examples:
  dws chat +messages-send --as user --chat-id <openConversationId> --markdown "## 周报" --idempotency-key <key>
  dws chat +messages-send --as user --user <userId> --msg-type file --file ./report.pdf --idempotency-key <key>
  dws chat +messages-send --as bot --robot-code <robotCode> --groups <openConversationId1>,<openConversationId2> --text "请提交周报"

      --at-mobiles strings             @ 的手机号（webhook） (default [])
      --at-open-dingtalk-ids strings   @ 的 openDingTalkId（user/bot 群聊；user 的 a2ui 卡片须与正文 <a atId> 一致） (default [])
      --at-user-ids strings            @ 的 userId（bot/webhook） (default [])
      --biz-card-id string             A2UI 业务标识，省略生成；不承诺消息幂等
      --body-stdin                     从 stdin 读取最多 256 KiB 正文；选中的正文参数必须为 -，不改变默认字面量行为
      --card-summary string            A2UI 卡片无法渲染时的降级文案；省略时为“互动卡片”，显式空白会被拒绝
      --chat-id string                 --group 的 lark-cli 对齐别名；受发送身份能力矩阵约束

      --file string                    工作目录内安全相对文件路径（user 的 file/audio/video；bot 仅单目标 file）

      --group string                   群 openConversationId（user/bot 群聊）；受发送身份能力矩阵约束
      --groups strings                 多个群 openConversationId（仅 bot；受发送身份能力矩阵约束，逐群返回 typed ledger，最多 100 个） (default [])
      --groups-file string             工作目录内相对文本文件（仅 bot；受发送身份能力矩阵约束），每行或逗号分隔一个群 openConversationId

When to use:
  - 以 user、bot 或 webhook 身份发送消息；user 的 Markdown 正文需要内联本地图片时先上传并发送单条富文本

Avoid when:
  - Bot 原生音视频、Webhook 富媒体及任意 Lark Card JSON 未接入；Thread 直接回复使用 +messages-reply --reply-in-thread，A2UI 创建可用 --a2ui-messages，更新仍用 chat message update-a2ui-card

Safety: effect=write  risk=medium  confirmation=user_required  idempotency=unknown
  Do not use --yes until the user explicitly confirms this operation.

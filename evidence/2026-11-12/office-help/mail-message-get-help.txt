根据邮件 ID 获取邮件完整内容，包含正文。

返回字段：
  message  邮件完整信息，包含主题、发件人、收件人、正文、附件等

错误说明：
  domain.notFound  该用户的邮箱不是由钉钉邮箱托管，无法完成操作

Usage:
  dws mail message get [flags]

Examples:
  dws mail message get --email user@company.com --id <messageId>  # 查询邮箱: dws mail mailbox list; 查询邮件 ID: dws mail message search

Flags:
      --email string   邮件所属邮箱地址 (必填)
  -h, --help           help for get
      --id string      邮件 ID (必填)

Global Flags:
      --client-id string       覆盖 OAuth 客户端 ID (钉钉 AppKey)
      --client-secret string   覆盖 OAuth 客户端密钥 (钉钉 AppSecret)
      --debug                  显示调试日志
      --dry-run                预览操作内容，不实际执行
      --fields string          筛选输出字段 (逗号分隔, 如: name,id,status)
  -f, --format string          输出格式: json|table|raw|pretty|ndjson|csv (default "json")
      --jq string              jq 表达式过滤输出 (如: '.items[] | .name')
      --mock                   使用 Mock 数据 (开发调试用)
      --profile string         一次性指定组织或账号；支持 corpId/corpName 与 userId/userName 组合，推荐使用 profile list 返回的 corpId:userId；多个按 CSV 逗号分隔
      --timeout int            HTTP 请求与文件直传超时时间 (秒)；文件直传最低保留 5 分钟 (default 30)
  -v, --verbose                显示详细日志
  -y, --yes                    跳过确认提示 (AI Agent 模式)

When to use:
  - 搜索或列表已返回 messageId，需要打开邮件内容时

Avoid when:
  - 只需筛选邮件列表时使用 message list 或 search

Safety: effect=read  risk=low  confirmation=not_required  idempotency=idempotent

## 已保存真实错误确实恢复

原parallel-hardening观察截至北京时间11月17日10:05:49的固定前缀：1871采样、15.604小时、0不可达、15错误采样，两路共24次DWSBusinessError。6946次history结果中31失败（30 API request_timeout、1未分类，3.266–3.473秒）；不是90秒受管进程超时，也无准入暂停/维护/显式resume。

31次错误之后两条路由均有更晚开始的complete同步且poll_error清除，最长观测上界47.764秒。审计未记录route，不能将紧邻成功或交替顺序伪造成同attempt的精确归属；“两路均恢复”才给出保守包含关系。24次已知路由错误全部下一采样清除并更新同步，最长30.159秒；窗口末尾无未恢复片段。采样延迟包含在上界中，不是SLA。

因此可证明这批短暂业务错误后的自动恢复，不能证明零错误、所有历史无遗漏、事务watermark或自然失效refresh。现有安全审计不带refresh生命周期元数据，未读凭据/改时钟/强制造失效。原固定cut为11月17日18:29:37，保持继续；到期审原run并在外部写review，不重置计时或合并旧run。

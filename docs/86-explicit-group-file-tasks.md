# E070 群文件显式交办

群普通文件仍不自动执行。用户可在同一群随后发送 `/agent --files ["订单.csv","说明.txt"] 合并并报告`，将先前文件明确交给当前运行器。

只选择同账号、会话和发送人的前50条事件内、30分钟内文件，最多8个不同文件名。缺失、重名、跨发送人、未来消息和路径名均拒绝；关联在下载前持久化。下载完整性沿用原件SHA校验，下载失败可等待恢复，取消或重启不复活任务，不猜最新附件。此功能不绑定Kimi，也不增加官方上传协议。

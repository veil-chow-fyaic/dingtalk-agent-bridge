## 关键问题记录

### 外部群事件 #937

报告包含内部/外部群对照、群主/成员角色对照和版本对照。历史能读但事件不来。10 月 21 日追加报告在 v1.0.64/v1.0.65 仍有目标群事件缺失，但该追加报告未核实群类型，因此不能断言同一根因。连接 ready 与业务投递覆盖必须分开检查。

### 自建应用映射 #909

App 存在、版本发布、用户登录成功仍可能遇到 UNIFIED_APP_ID_NOT_FOUND；报告中默认 OAuth 应用可以收到私聊。第一轮不先引入自建 App，不把机器人凭据当用户凭据。

### 加密媒体 #1429

纯图片可只返回空壳，资源台账可能 discovered=0、failed=0、ok=true。贡献者说明当时仅支持文字解密，尚无图片/文件资源解密。不能据空资源列表断言消息没有附件，也不把有权在客户端阅读等同于取得资源 API 权限。

### 定制版下载 #1215

报告限定 SupMate 企业定制版和特定资源；获取 URL 成功、立即下载仍 403。不可泛化为全部图片失败。不要通过猜 URL、修改 mediaId 前缀规避鉴权。

### 多群与订阅 #890

旧版本存在逗号多群静默只处理第一个的报告；不据此断言最新版仍有 bug。第一轮只订阅唯一测试群，避免用 all-group 扩大范围。

各 issue 的链接、查询日期及状态见资料来源与 evidence 中的公开元数据。

2026-11-11 单人验收结果见 [实测报告](14-solo-test-report.md)；多人项目为 skipped_by_user，不是 failed 或 passed。

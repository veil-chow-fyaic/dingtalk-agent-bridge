# 合成测试素材

这些素材不含业务数据，只能发送到用户授权且配置明确的测试路由。组织/联系人不是产品常量；不要改原件内容后仍用旧摘要声称一致。

- TXT/CSV：文本及金额计算任务输入。
- PNG：320×180测试图和第二张图片；PDF为图形文档。
- DOCX/XLSX：真实OOXML小型办公附件，DOCX含单段合成标记。
- ZIP：包含TXT的归档；WAV：1秒440Hz；MP4：1秒蓝色视频。
